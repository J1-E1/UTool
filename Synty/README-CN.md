## 最佳实践

### 性能优化
- 使用静态批处理
- 合并网格
- 启用遮挡剔除
- 实现 LOD 组

### 材质
- 启用 GPU 实例化
- 调整平滑度
- 为发光元素使用自发光

### 角色自定义
- 交换头部、身体、配饰部件
- 混合不同包组件
- 支持运行时自定义

---

## 常见问题

**模型太暗/太亮** - 调整材质平滑度

**动画无法播放** - 检查导入设置和绑定

**纹理模糊** - 增加最大纹理大小
