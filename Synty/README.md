## Best Practices

### Performance
- Use static batching
- Combine meshes
- Enable occlusion culling
- Implement LOD groups

### Materials
- Enable GPU instancing
- Adjust smoothness
- Use emission for glowing elements

### Character Customization
- Swap head, body, accessory parts
- Mix different pack components
- Support runtime customization

---

## Common Issues

**Models too dark/shiny** - Adjust material smoothness

**Animations not playing** - Check import settings and rig

**Blurry textures** - Increase max texture size
