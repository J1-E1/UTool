## 概述

Unity 的综合可视化脚本框架，实现无代码游戏开发。无需编写代码即可创建复杂的游戏机制、角色行为和交互系统。

---

## 什么是 Game Creator？

Game Creator 通过以下方式提供可视化的节点系统来创建游戏逻辑：
- **触发器** - 激活动作的事件（点击、碰撞等）
- **动作** - 按顺序执行的操作
- **条件** - 决策的逻辑门
- **变量** - 数据存储和操作
- **状态机** - 复杂行为管理

## 快速开始

### 安装

1. 从 Unity Asset Store 导入 Game Creator
2. 安装所需依赖项（如有）
3. 打开 Game Creator 欢迎窗口
4. 按照设置向导操作

### 创建第一个交互

1. 向 GameObject 添加 **触发器** 组件
2. 选择触发器类型（例如"开始时"、"点击时"）
3. 向触发器添加 **动作**（例如"移动角色"、"播放动画"）
4. 在播放模式下测试

## 可视化脚本基础

### 触发器

触发器检测事件并激活动作：
- **开始时** - 场景加载时执行
- **点击时** - 点击时执行
- **碰撞时** - 对象碰撞时执行
- **按键时** - 按下按键时执行
- **变量改变时** - 变量更改时执行

### 动作

动作按顺序执行操作：
- 角色动作（移动、跳跃、播放动画）
- 相机动作（切换镜头、震动、缩放）
- 音频动作（播放声音、音乐控制）
- 变量动作（设置、递增、比较）
- 流程控制（等待、循环、条件）

### 条件

条件评估逻辑并分支执行：
- 比较变量
- 检查玩家状态
- 评估距离
- 测试库存内容

## 最佳实践

1. **使用注释组织** - 为触发器和动作使用描述性名称
2. **使用变量** - 将可重用的值存储在全局或局部变量中
3. **模块化设计** - 将复杂逻辑分解为较小的触发器
4. **频繁测试** - 经常运行播放模式以尽早发现问题
5. **使用条件** - 添加逻辑门使行为动态化

## 常见工作流程

### 角色移动
1. 向 GameObject 添加角色组件
2. 配置输入设置
3. 添加相机控制器用于第三人称视图
4. 测试移动并调整参数

### 交互对象
1. 向对象添加碰撞器
2. 添加"交互时"触发器
3. 添加动作（播放声音、更改材质、生成物品）
4. 配置交互提示

### 保存系统
1. 定义要保存的数据（变量、库存等）
2. 向菜单添加保存/加载动作
3. 测试跨会话的保存持久性
