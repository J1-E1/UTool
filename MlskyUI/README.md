## Overview

Comprehensive UI framework with customizable themes, pre-built components, and smooth animations.

---

## Available Themes

### Dark UI
Modern dark theme for immersive gaming.

[View Dark UI Documentation](./DarkUI.md)

### Modern UI
Clean light theme for casual and mobile games.

[View Modern UI Documentation](./MordenUI.md)

---

## Key Features

- **Theme Management** - Switch between themes
- **UI Components** - Buttons, sliders, modals, selectors
- **Gamepad Support** - Full gamepad and keyboard/mouse
- **Localization** - Multi-language support
- **Achievement System** - Built-in tracking
- **Animation Effects** - Smooth transitions

---

## Quick Start

1. Import MlskyUI package
2. Add UI Manager prefab to scene
3. Configure theme settings
4. Use pre-built components

---

## Core Components

### UI Manager
Manages theme, colors, and UI updates.

### Panel Manager
Handles navigation between panels.

### Gamepad Handler
Detects and manages gamepad input.
