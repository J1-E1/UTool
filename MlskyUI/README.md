# MlskyUI - Modern UI Framework

## Overview / 概述

**EN:** MlskyUI is a comprehensive UI framework for Unity featuring customizable themes, pre-built components, and smooth animations for creating professional game interfaces.

**CN:** MlskyUI 是一个综合的 Unity UI 框架，具有可定制主题、预构建组件和流畅动画，用于创建专业的游戏界面。

---

## Available Themes / 可用主题

### Dark UI / 深色 UI
Modern dark theme with sleek components perfect for immersive gaming experiences.

现代深色主题，具有流畅的组件，非常适合沉浸式游戏体验。

[View Dark UI Documentation](./DarkUI.md)

### Modern UI / 现代 UI
Clean and minimal light theme suitable for casual and mobile games.

简洁明快的浅色主题，适合休闲和移动游戏。

[View Modern UI Documentation](./MordenUI.md)

---

## Key Features / 主要特性

**EN:**
- **Theme Management** - Switch between dark and modern themes
- **UI Components** - Buttons, sliders, modals, selectors, and more
- **Gamepad Support** - Full gamepad and keyboard/mouse integration
- **Localization** - Multi-language support system
- **Achievement System** - Built-in achievement tracking and display
- **Animation Effects** - Smooth transitions and visual feedback

**CN:**
- **主题管理** - 在深色和现代主题之间切换
- **UI 组件** - 按钮、滑块、模态框、选择器等
- **手柄支持** - 完整的手柄和键盘/鼠标集成
- **本地化** - 多语言支持系统
- **成就系统** - 内置成就跟踪和显示
- **动画效果** - 流畅的过渡和视觉反馈

---

## Quick Start / 快速开始

**EN:**
1. Import MlskyUI package into your Unity project
2. Add UI Manager prefab to your scene
3. Configure theme settings (dark or modern)
4. Use pre-built UI components or customize your own

**CN:**
1. 将 MlskyUI 包导入到 Unity 项目
2. 将 UI Manager 预制体添加到场景
3. 配置主题设置（深色或现代）
4. 使用预构建的 UI 组件或自定义

---

## Core Components / 核心组件

### UI Manager / UI 管理器
Central component for managing theme, colors, and UI updates.

管理主题、颜色和 UI 更新的核心组件。

### Panel Manager / 面板管理器
Handles navigation between different UI panels and windows.

处理不同 UI 面板和窗口之间的导航。

### Gamepad Handler / 手柄处理器
Detects and manages gamepad input, switching between gamepad and keyboard/mouse modes.

检测和管理手柄输入，在手柄和键盘/鼠标模式之间切换。
