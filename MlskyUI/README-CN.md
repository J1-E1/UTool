## 概述

综合 UI 框架，具有可定制主题、预构建组件和流畅动画。

---

## 可用主题

### 深色 UI
现代深色主题，适合沉浸式游戏。

[查看深色 UI 文档](./DarkUI.md)

### 现代 UI
简洁浅色主题，适合休闲和移动游戏。

[查看现代 UI 文档](./MordenUI.md)

---

## 主要特性

- **主题管理** - 主题切换
- **UI 组件** - 按钮、滑块、模态框、选择器
- **手柄支持** - 完整的手柄和键鼠支持
- **本地化** - 多语言支持
- **成就系统** - 内置成就跟踪
- **动画效果** - 流畅过渡

---

## 快速开始

1. 导入 MlskyUI 包
2. 添加 UI Manager 预制体
3. 配置主题设置
4. 使用预构建组件

---

## 核心组件

### UI 管理器
管理主题、颜色和 UI 更新。

### 面板管理器
处理面板间导航。

### 手柄处理器
检测和管理手柄输入。
